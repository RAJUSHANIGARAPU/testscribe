API Reference

TestScribe API lets you generate test cases programmatically from your CI/CD pipeline or test management tools. The API is a simple JSON REST API — send your user story or OpenAPI spec, get back structured test cases.

Base URL: https://testscribe.ai/api/v1

Authentication

All API requests must include an API key in the X-API-Key header. You can also use a Bearer JWT obtained from POST /auth/login. Get your API key from the dashboard.

API Key (recommended for CI/CD)

curl https://testscribe.ai/api/v1/generations \
  -H "X-API-Key: tsc_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"input_type":"user_story","input_text":"...","output_format":"gherkin"}'

Bearer JWT

curl https://testscribe.ai/api/v1/generations \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"input_type":"user_story","input_text":"...","output_format":"gherkin"}'
POST

/generations

Submit a user story, requirements document, OpenAPI spec, or Jira text for test case generation. Returns a generation object. If the status is pending, poll GET /generations/{id} until complete.

Request body

Field Type Required Description
input_type string Required One of: user_story, requirements, openapi, jira, raw
input_text string Required The raw text of the user story, spec, or document. Max tokens depend on your plan.
output_format string Required One of: gherkin, tabular, pytest. Free plan: gherkin only.
persona string Optional Custom test persona identifier (Pro plan only). Controls tone and depth of security scenarios.

Response fields

FieldTypeDescription
idstringUUID of the generation
statusstringpending, processing, completed, or failed
output_textstring | nullGenerated test cases. Present when status is completed.
tokens_usedinteger | nullTotal tokens consumed by this generation
created_atstringISO 8601 timestamp
error_messagestring | nullHuman-readable error description when status is failed

curl example

curl -X POST https://testscribe.ai/api/v1/generations \
  -H "X-API-Key: tsc_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "input_type": "user_story",
    "input_text": "As a user, I want to log in with email and password so I can access my account.\n\nAC:\n- Valid credentials → redirect to dashboard\n- Invalid credentials → show error message\n- After 5 failed attempts → lock account for 15 minutes",
    "output_format": "gherkin"
  }'

Python example

import requests

response = requests.post(
    "https://testscribe.ai/api/v1/generations",
    headers={"X-API-Key": "tsc_your_api_key_here"},
    json={
        "input_type": "user_story",
        "input_text": "As a user, I want to log in...",
        "output_format": "gherkin",
    }
)
data = response.json()

if data["status"] == "completed":
    print(data["output_text"])
elif data["status"] == "pending":
    # Poll until done
    gen_id = data["id"]
    while True:
        r = requests.get(
            f"https://testscribe.ai/api/v1/generations/{gen_id}",
            headers={"X-API-Key": "tsc_your_api_key_here"},
        )
        result = r.json()
        if result["status"] in ("completed", "failed"):
            break
        time.sleep(2)
    print(result.get("output_text"))
GET

/generations/{id}

Retrieve a single generation by ID. Use this to poll for the result of an async generation.

Status values

StatusMeaning
pendingQueued, not yet started
processingGeneration in progress
completedDone. output_text is populated.
failedAn error occurred. See error_message.

Recommended polling strategy

Poll every 2 seconds, up to 30 attempts (60 seconds). Most generations complete in 3–10 seconds. 

curl https://testscribe.ai/api/v1/generations/<id> \
  -H "X-API-Key: tsc_your_api_key_here"
GET

/generations

List your recent generations. Returns a paginated array of generation objects, newest first.

Query parameters

ParameterTypeDefaultDescription
limitinteger20Number of results to return. Max 100.
offsetinteger0Pagination offset.
statusstring—Filter by status: completed, failed, etc.
 
curl "https://testscribe.ai/api/v1/generations?limit=10&status=completed" \
  -H "X-API-Key: tsc_your_api_key_here"

Errors

All errors follow a consistent JSON shape: 

{
  "detail": "Human-readable error message",
  "code": "ERROR_CODE"
}
HTTP StatusCodeWhen it occurs
400 VALIDATION_ERROR Missing required fields, invalid input_type or output_format
401 UNAUTHORIZED Missing, invalid, or expired API key / token
402 LIMIT_EXCEEDED Monthly generation limit reached for your plan
403 FORBIDDEN Feature not available on your plan (e.g. pytest format on free tier)
404 NOT_FOUND Generation ID does not exist or belongs to another user
413 INPUT_TOO_LARGE Input text exceeds the token limit for your plan
429 RATE_LIMITED Too many requests per minute. Check Retry-After header.
500 INTERNAL_ERROR Unexpected server error. Retry with exponential backoff.
503 AI_UNAVAILABLE Upstream AI provider temporarily unavailable. Retry after a few seconds.
